# Панель управління УДО

Українська панель для щоденної роботи відділу УДО в GTA RP. Стиль Soft Dark Minimal, адаптивний інтерфейс.

## Можливості

- Особовий склад та особові справи.
- Підвищення, RP-чеклісти, заліки, практика та КД 48/72/96/168 годин.
- Пости охорони, патрулювання, шикування, тен-коди.
- Накази, рапорти, перевірки та набір.
- Шаблони Discord, державної хвилі та ігрового чату; копіювання, пошук і фільтри.
- Завантаження скріншотів, перевірка керівником та журнал змін.

## Технології

React + Vinext, Cloudflare Workers, D1 (записи), R2 (скріншоти). Репозиторій містить лише вихідний код і початкові шаблони, без робочої бази, файлів користувачів і секретів.

## Розгортання

Це серверний застосунок: GitHub Pages не виконує API та не замінює D1/R2. Саме завантаження коду в GitHub не запускає сайт. Поточна робоча версія опублікована через Sites. У `.openai/hosting.json` залишені логічні прив’язки DB і BUCKET; ідентифікатор приватного проєкту не експортується.

Для окремого хостингу необхідно налаштувати Cloudflare D1/R2 та захист доступу до всіх маршрутів, включно з API. У поточному розгортанні доступ контролює Sites. Не публікуйте Worker з незахищеними API.

## GitHub + Cloudflare

Конфігурація окремого захищеного запуску описана в [CLOUDFLARE.md](CLOUDFLARE.md). Команди Workers Builds: `npm run build:cloudflare` та `npm run deploy:cloudflare`. Для публікації потрібно створити D1/R2 і налаштувати секрет входу у своєму акаунті Cloudflare.
