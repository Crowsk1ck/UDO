# Панель управління УДО

Українська панель для щоденної роботи відділу УДО в GTA RP. Стиль Soft Dark Minimal, адаптивний інтерфейс.

## Можливості

- Особовий склад та особові справи.
- Підвищення, RP-чеклісти, заліки, практика та КД 48/72/96/168 годин.
- Пости охорони, патрулювання, шикування, тен-коди.
- Накази, рапорти, перевірки та набір.
- Шаблони Discord, державної хвилі та ігрового чату; копіювання, пошук і фільтри.
- Посилання на докази ImgBB, перевірка керівником та журнал змін.

## Технології

React + Vinext, Cloudflare Workers, D1 (записи та посилання ImgBB). Репозиторій містить лише вихідний код і початкові шаблони, без робочої бази, файлів користувачів і секретів.

## Доступ

Керівник входить через `/login` як `admin` з паролем із секрету Cloudflare `UDO_ADMIN_PASSWORD`. Він створює особову справу, а потім у розділі «Акаунти» видає співробітнику власний логін та пароль. Співробітники працюють зі своїми рапортами й підвищеннями; погоджує їх керівник. Доступ можна заблокувати, пароль — перевстановити.

## Перевірка

```sh
node --experimental-strip-types --test tests/accounts.test.mjs
npx tsc --noEmit
```

## GitHub + Cloudflare

Це серверний застосунок із D1: GitHub Pages не виконує його API. Налаштування описано в [CLOUDFLARE.md](CLOUDFLARE.md). Команди Workers Builds: `npm run build:cloudflare` та `npm run deploy:cloudflare`. Для збірки потрібна змінна `CF_D1_DATABASE_ID`, для входу керівника — runtime-секрет `UDO_ADMIN_PASSWORD`. Міграції бази запускаються перед публікацією Worker.
